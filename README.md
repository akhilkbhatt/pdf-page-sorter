# PDF Page Sorter

Reorder, rotate and delete the pages of a PDF, right in your browser. Your file is never uploaded.

**Use it:** https://akhilkbhatt.github.io/pdf-page-sorter/

- Open a PDF or drop one on the page (add more files to combine them)
- Drag pages to reorder; click, Shift-click or Cmd/Ctrl-click to select
- Arrow keys move selected pages, `R` rotates, `Delete` removes, Cmd/Ctrl+Z undoes
- **Save PDF** downloads the new file

Built with [pdf.js](https://mozilla.github.io/pdf.js/), [pdf-lib](https://pdf-lib.js.org/) and [SortableJS](https://sortablejs.github.io/Sortable/).
